# System Tuneup GUI

**Графическая оболочка для безопасного тюнинга Linux Mint / Ubuntu / Debian.**
Один файл AppImage — без установки, зависимостей и внешних скриптов.

> Автор: **Дмитрий Свистунов (Dmitry Svistunov)**
> Актуальная версия: см. [Releases](../../releases)

---

## Что это такое

System Tuneup GUI — утилита для домашнего и игрового ПК, которая собирает
в одном окне проверенные твики системы: логи, ядро и загрузка, видеокарта,
звук, память, диски, игры и автообновления. Каждая опция имеет понятное
описание, индикатор «применено / не применено», кнопку просмотра изменяемого
файла и функцию отката с автоматическим бэкапом.

## Возможности

- **Тюнинг**: 16+ опций с подробными описаниями (rsyslog, journald, GRUB,
  CoreCtrl/VRR/RADV/MESA, PipeWire, swappiness, sysctl, ntsync, ntfs3 и др.)
- **Диски**: добавление `noatime,nodiratime` в `/etc/fstab` для выбранных
  разделов; симлинки `compatdata` для Steam-библиотек на NTFS-дисках
- **Службы**: таблица состояния «лишних» служб с описаниями, пакетное
  включение/отключение
- **Статус**: полная сводка о системе (ОС и битность, видеокарта, экран,
  ОЗУ, диски, swap, ядро, окружение) + цветной список твиков и служб
- **Безопасность**: режим «Сухой прогон», откат любых изменений,
  бэкапы в `~/system-tuneup-backups` (последняя копия каждого файла)
- **Интерфейс**: RU/EN (автоопределение языка системы), светлая/тёмная тема,
  масштабирование под низкие экраны (нетбуки), копирование текста из любых
  полей, встроенный просмотрщик системных файлов
- **Автообновления**: systemd-таймер обновления APT/Flatpak по расписанию
